# 流光下载器需求说明

文档状态：main（v1.0.10）

更新日期：2026-09-02

## 产品定位

流光下载器是流光 App 的下载伴侣。流光负责发现、解析和播放在线资源；下载器接收用户确认的 m3u8 或 MP4 链接，将受支持的资源保存为本地 MP4 文件。

应用仅面向用户自有或已获授权下载的资源。不提供 DRM 绕过、资源站聚合或访问控制规避能力。

## 当前范围

### 输入与流光对接

- 启动时读取剪贴板；仅接受 `http://` 或 `https://` 开头，且包含 `.m3u8` 或 `.mp4` 的链接。
- 用户可以手动粘贴或编辑 m3u8 / MP4 链接和输出文件名。
- 流光 App 可以通过 `liuguangdl://download/add` deep link 或兼容 Intent extra 预填链接和文件名；下载器始终要求用户点击“确定”后才开始任务。
- 地址框支持一行一个链接，自动去重，单批最多 20 条；流光也可以通过 `DOWNLOAD_ITEMS_JSON` extra 传递 URL 与标题数组。
- 第一版不支持为单个任务配置 `Referer`、`Cookie`、`User-Agent` 等请求头。

### 下载与输出

- master playlist 解析 `#EXT-X-STREAM-INF`，默认选择最高分辨率；分辨率相同或缺失时选择最高 `BANDWIDTH`，无法判断时回退第一个可用播放流。
- 普通 TS-HLS 和 AES-128 TS-HLS 下载分片后使用 Android `MediaExtractor` / `MediaMuxer` 合并为单个 MP4。
- fMP4 HLS 下载 `EXT-X-MAP` 初始化片段和媒体分片，先还原 fragmented MP4，再通过 Android 媒体组件重封装为普通 MP4。
- `EXT-X-BYTERANGE` 支持显式偏移和同资源连续分片的隐式偏移；下载时要求服务器返回匹配的 `206`、`Content-Range` 和字节长度。
- MP4 直链直接下载并发布为 MP4，不经过 HLS 解析和合并。
- 任务队列按照“最大并行任务数”调度；HLS 分片下载线程数可配置，两个设置下限均为 1。
- 下载由前台服务执行，切换页面或退出 Activity 不会主动取消任务。通知用于保活和任务入口，不按每个分片实时刷新进度。
- 默认输出目录为 `Downloads/liuguang-download`；也可通过 Android Storage Access Framework 选择并持久授权自定义目录。
- 创建任务前估算资源体积和峰值空间；空间不足时禁止创建，同名文件按 `名称 (1).mp4` 自动重命名。

### 任务管理

- 下载页按全部、队列中、下载中、已完成、失败筛选任务。
- 支持开始、暂停、继续、重新下载、删除任务记录、复制下载链接和打开已完成文件。
- 任务历史使用 SharedPreferences + JSON 持久化，应用重新进入后会恢复任务记录。
- 暂停任务会保留已下载的缓存以便继续；重新下载会清除该任务缓存。删除运行中或等待中的任务会取消请求并清理任务缓存，删除已暂停或失败任务目前只删除任务记录。
- 当前不支持重命名已输出文件或删除已输出的本地视频。
- 网络中断、`408/429/5xx` 最多自动重试 2 次，等待 2 秒和 4 秒；权限、链接失效、空间、格式和合并错误不自动重试。

### 版本更新

- 应用启动时自动检查 GitHub Releases；设置页可以手动检查更新。
- 仅接受正式 Release 中的 APK 资产，下载前后校验 HTTPS 来源、GitHub 提供的 SHA-256、应用包名、Android `versionCode` 和签名证书。
- 下载完成后调用系统安装器；Android 8.0 及以上首次安装需要用户在系统设置中授权该应用安装未知来源 APK，最终安装仍由用户确认。

## 非目标与限制

- 不内置资源站。
- 不支持 DRM、Widevine、FairPlay、SAMPLE-AES。
- 不支持手动选择清晰度或自定义请求头。
- fMP4 不支持运行中切换初始化片段，也不支持 TS/fMP4 混合时间线；加密 fMP4 初始化片段必须显式提供 AES-128 IV。
- fMP4 含 `EXT-X-DISCONTINUITY` 时直接拒绝，避免在未重建轨道和时间线的情况下生成不可预期文件。
- MP4 合并依赖目标设备的 Android 媒体组件；复杂时间线、格式切换或不兼容轨道可能失败并显示任务原因。

## 验收标准

- 剪贴板、手动输入和流光 deep link 均能在用户确认后创建受支持的下载任务。
- master playlist 按最高分辨率/最高带宽选择默认清晰度。
- 普通或 AES-128 TS-HLS 下载完成后，在默认或已授权的自定义目录中得到单个 MP4。
- 单初始化片段 fMP4 与标准 BYTERANGE HLS 下载后得到可读取音视频轨道的单个 MP4。
- MP4 直链可下载并保存为 MP4。
- 暂停任务可以继续，重新进入应用后可以看到历史任务记录。
- 多链接或批量 JSON 输入会在统一确认后创建多个独立任务。
- 应用能识别 GitHub 最新正式 Release；安装包安全校验失败时不会调用系统安装器。
